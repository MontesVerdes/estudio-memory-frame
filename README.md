# Estudio Memory Frame

El estudio de vídeo de Memory Frame para tu ordenador: editas tus vídeos y fotos, pones música y voz, añades **subtítulos automáticos** y exportas para Instagram, TikTok o donde quieras.

**Tu voz y tus vídeos no salen de tu ordenador.** Todo se hace en tu equipo, también los subtítulos. Lo único que se descarga de internet es el «modelo de voz» (470 MB), una sola vez, la primera vez que pides subtítulos.

## Descargar

Los botones siempre llevan a la última versión:

| Sistema | Descarga |
|---|---|
| Windows | [Estudio-Memory-Frame-win-x64.exe](https://github.com/MontesVerdes/estudio-memory-frame/releases/latest/download/Estudio-Memory-Frame-win-x64.exe) |
| Mac (Apple Silicon: M1, M2, M3, M4) | [Estudio-Memory-Frame-mac-arm64.dmg](https://github.com/MontesVerdes/estudio-memory-frame/releases/latest/download/Estudio-Memory-Frame-mac-arm64.dmg) |
| Extensión de Claude | [Estudio-Memory-Frame.mcpb](https://github.com/MontesVerdes/estudio-memory-frame/releases/latest/download/Estudio-Memory-Frame.mcpb) |

Versiones anteriores: [todas las versiones](https://github.com/MontesVerdes/estudio-memory-frame/releases).

## Instalar

**Windows**
1. Descarga el `.exe` y haz doble clic.
2. Si Windows avisa de que no conoce al editor, pulsa «Más información» y luego «Ejecutar de todas formas».
3. Sigue los pasos del instalador (puedes elegir la carpeta). Se crea un acceso directo en el escritorio.

**Mac**
1. Descarga el `.dmg`, ábrelo y arrastra «Estudio Memory Frame» a la carpeta Aplicaciones.
2. La primera vez, **clic derecho sobre la app › Abrir › Abrir** (la app aún no tiene firma de Apple). Las siguientes veces se abre con doble clic.

**Extensión de Claude** (para pedirle a Claude que edite en el estudio)
1. Abre la app de Claude en tu ordenador.
2. Haz doble clic en el archivo `.mcpb` y pulsa «Instalar».
3. Deja el estudio abierto mientras hablas con Claude.

## Qué hay dentro

- Edición con varias pistas: vídeo, foto, texto, música y voz.
- Subtítulos automáticos en español o inglés, con varios estilos que puedes cambiar a la vez o uno a uno.
- Exportación lista para redes.
- El estudio te avisa cuando hay una versión nueva (puedes quitarlo en el menú Ayuda). No se instala nada solo: tú decides cuándo descargarla.

## Privacidad

- Tus vídeos, fotos y tu voz se quedan en tu ordenador. No hay cuenta, ni nube, ni envío de datos.
- La búsqueda de versiones nuevas es una petición normal a GitHub, sin ningún dato tuyo.
- Los instaladores no llevan claves ni datos personales.

## ¿Algo no va bien?

Escríbenos a Memory Frame y cuéntanos qué versión tienes y qué estabas haciendo.
